Frequently asked

Where is my data stored?

Entirely on your device. TaxDeduct has no account and no server. If you delete the app, the data goes with it — export a backup first if you need it.

How do I export for my accountant?

Open the Summary tab and tap “Export for your accountant (CSV)”. This is a Pro feature. The file goes through the normal iOS share sheet, so you can email it or save it to Files.

How do I back up or move to a new phone?

Settings → Backup → “Export encrypted backup”. Choose a passphrase and keep it safe — without it the file cannot be recovered. On the new device, use “Restore from backup”.

Automatic mileage is not recording.

Check three things: the toggle is on in the Mileage tab; iOS Settings → Privacy & Security → Location Services → TaxDeduct is set to “Always”; and Low Power Mode is off, since it can pause background location updates.

Why does TaxDeduct ask for “Always” location?

So it can detect a drive while the app is in the background. Only distance is saved — raw coordinates are never stored or transmitted.

How do I restore my subscription?

Settings → Restore purchase. Make sure you are signed in with the same Apple ID you used to subscribe.

How do I cancel?

iOS Settings → your name → Subscriptions → TaxDeduct. Cancelling stops the next renewal; the current period still runs to the end.

How do I delete everything?

Settings → Data → “Delete all records”. This cannot be undone.

Does TaxDeduct file my taxes?

No. It is a record-keeping tool. Rates and rules change — always confirm with your tax authority or accountant.
